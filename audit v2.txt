### **2. PROJECT ARCHITECTURE**

```
User (Browser)
    ↓
Next.js Frontend (Port 3000)
    ↓ [Axios HTTP calls]
Spring Boot REST API (Port 8080)
    ├── Controllers (thin routing layer)
    ├── Services (business logic)
    │   ├── InputService
    │   ├── RecordingService
    │   ├── TranscriptionService
    │   ├── AnalysisService
    │   ├── ActionItemService
    │   ├── DocumentService
    │   ├── DashboardService
    │   ├── AuthService
    │   └── AiToolsService
    ├── Repositories (Spring Data JPA)
    └── Security (JWT filter + UserDetails)
    ↓
PostgreSQL (Port 5432)

External Integrations:
├── Groq API (LLM analysis)
└── Whisper ASR Service (Port 9000 - local transcription)
```

**Data Flow Example (Voice → Brief):**
1. User uploads/records audio → Input entity created
2. Backend calls Whisper service → Recording + Transcript created
3. User clicks "Analyze" → AnalysisService calls Groq API
4. Groq returns: summary, key points, decisions, risks, opportunities
5. Analysis entity stored with extracted data
6. Frontend displays results; user confirms/edits
7. ActionItems extracted and saved

### **8. DOCKER ARCHITECTURE**

**`docker-compose.yml` Services:**

```
Network: default (bridge)

1. postgres:16-alpine
   ├── Port: 5432
   ├── Volumes: execflow-pg-data
   ├── Env: POSTGRES_DB=execflow, POSTGRES_USER=execflow, POSTGRES_PASSWORD=execflow
   ├── Health: pg_isready -U execflow (5s interval, 10 retries)
   └── Status: All services depend on this being healthy

2. whisper (onerahmet/openai-whisper-asr-webservice:latest)
   ├── Port: 9000
   ├── Volumes: execflow-whisper-cache (~150MB model, persistent)
   ├── Env: ASR_MODEL=base (swap to small/medium for accuracy)
   ├── Health: No explicit health check (backend retries)
   └── Status: Backend depends on this starting

3. backend (./execflow-backend)
   ├── Build: Multi-stage Dockerfile (Java 17, Maven)
   ├── Port: 8080
   ├── Volumes: execflow-uploads (file storage)
   ├── Env: DB_URL, DB_USERNAME, DB_PASSWORD, JWT_SECRET, GROQ_*, WHISPER_*, STORAGE_*
   ├── Depends: postgres (healthy), whisper (started)
   ├── Health: No explicit check (frontend polls /health)
   └── Status: Runs Spring Boot application

4. frontend (./execflow-frontend)
   ├── Build: Multi-stage Dockerfile (Node 20, npm build)
   ├── Port: 3000
   ├── Env: NEXT_PUBLIC_API_BASE_URL=http://backend:8080/api/v1
   ├── Depends: backend (started)
   └── Status: Runs Next.js production or dev server

Volumes (persistent data):
├── execflow-pg-data (PostgreSQL database files)
├── execflow-uploads (Audio/file uploads)
└── execflow-whisper-cache (Whisper model weights ~150MB)
```

**Build Flow:**
1. `docker compose up --build` triggers both Dockerfiles
2. Backend image: Maven builds JAR, then runtime image runs it
3. Frontend image: npm build → .next output, then runtime runs next start
4. Services start in dependency order (postgres → whisper → backend → frontend)
